# School Emergency Support System

Веб-ориентированная информационная система дистанционной поддержки школьного образовательного процесса в условиях чрезвычайных ситуаций.

## Возможности

- 👥 Управление пользователями (админ, учитель, ученик)
- 📚 Управление классами и расписанием
- 🎥 Онлайн-уроки с WebRTC
- 📊 Контроль посещаемости и успеваемости
- 📝 Домашние задания
- 📈 Отчеты в PDF и Excel
- 🚨 Режим чрезвычайной ситуации
